Get the live Unicommerce session

Five steps, about two minutes. This is the one manual thing the platform needs from a human, after this, it keeps itself alive on its own.

🔒
Don't forward the password over chat/email. Share it the way you'd share any login, in person, a password manager, or a call. This page intentionally doesn't repeat it.
1

Open Unicommerce

In a normal browser tab, go to oppdoor.unicommerce.co.in, this is the production account.

2

Log in as the automation account

Username: sc.automations@opptra.com, password as shared separately. Note the "s", automations, plural.

oppdoor.unicommerce.co.in/login
3

Tell us what the login asked for

Did anything besides username + password show up, a CAPTCHA, an OTP, a code sent somewhere? Just note yes/no, you'll report this back.

4

Open DevTools and find JSESSIONID

Right-click the page → Inspect → Application tab → Cookies → click the site. Find the row named exactly JSESSIONID and copy its Value column only.

DevTools, Application → Cookies

A real value looks like the highlighted row above: long, random letters and numbers, no dashes. If what you copied has dashes in groups of 8-4-4-4-12, it's the wrong field, keep looking.

5

Paste it into the platform

Open the Opptra SCM Platform → Admin tab → Manual paste → paste the value → Save session.

This is what the Dashboard's session card shows when it worked. If it still says DEAD, the value was probably wrong, go back to step 4.

Report back

  • Did step 3 show a CAPTCHA or OTP? Yes / no.
  • Did the dashboard turn ALIVE?
  • If no CAPTCHA/OTP appeared: a HAR capture of this login (DevTools → Network → Preserve log → do the login → Save all as HAR) lets the platform log itself in automatically from now on, this manual step would never be needed again.

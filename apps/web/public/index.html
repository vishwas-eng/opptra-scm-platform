Browser Extensions

          
Some automations use a small Chrome extension. Download, install once, and follow the steps below.


          

            
① Opptra Session Helper recommended

            
Captures your Unicommerce session after you log in, so the platform can keep it alive. You install it once; then whenever the session expires you just log into Unicommerce and click the helper.

            ⤓ Download Session Helper (.zip)
            
    
              
  1. Download the .zip above and unzip it to a folder you'll keep (e.g. ~/opptra-session-helper).
    2. 
              
  2. Open Chrome → go to chrome://extensions.
    3. 
              
  3. Turn on Developer mode (top-right toggle).
    4. 
              
  4. Click Load unpacked → select the unzipped folder.
    5. 
              
  5. Open the extension, paste your Ingest Token (get it from the Admin tab → “Session Helper token”) and the platform URL. Click Save.
    6. 
              
  6. When the platform says “Re-login needed”, click Re-login to Unicommerce, log in (do the CAPTCHA), then click the helper’s Capture session. Done — session goes ALIVE.
    7. 
            

          


          

            
② Bulk Invoice / E-way Bill Downloader

            
Select orders in Unicommerce and bulk-download invoice + e-way PDFs. Standalone — no token needed.

            ⤓ Download Bulk Downloader (.zip)
            
    
              
  1. Download and unzip the .zip above.
    2. 
              
  2. Chrome → chrome://extensions → enable Developer mode.
    3. 
              
  3. Load unpacked → pick the unzipped folder.
    4. 
              
  4. Open Unicommerce, go to the orders list, click the extension, choose what to download.
    5.

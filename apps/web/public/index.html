Return + Re-dispatch

Cancel the wrong SO, punch + allocate the correct one, drive it to delivered, one order at a time so inventory never leaks to B2C.

Batch, original → correct SO pairs

The manager's flow: paste the sheet of pairs, one per line as originalSO, correctSO. Each pair cancels the wrong SO and processes the correct one, sequentially, so inventory never leaks.

E-way Bill Generation

Same as the old Apps Script tool: download the Excel template, fill one row per SO (transporter details per row), upload it, then generate. Already-created e-way bills offer a PDF download. Dry run validates without creating.

SO Number Transporter GSTIN Transporter Name Mode Vehicle No Distance Doc No Doc Date Vehicle Type

Only SO Number is required. GSTIN must be 15 characters when filled. Mode defaults to ROAD, vehicle type to REGULAR.

Inward / Outward / Full-cycle

Inward brings stock in (PO → GRN → put-away or adjust). Outward sells it (Sale Order → allocate → invoice). Full-cycle does both, gated.

A retry with the same result is safe, steps are idempotent (never double-creates a PO/invoice).

ASN / Packaging Compile

Enter one SO. The platform finds the order across facilities, detects its marketplace automatically, and generates that marketplace's ASN file for this SO only.

Home Centre Sync

GCC only. Pulls Home Centre (Vinculum) orders and punches a Unicommerce B2C sale order (create customer → SO). Confirm / ship / label on Vinculum is a separate step once capture is ready. Manual only — safe when there are zero orders (returns success, nothing to do).

Use Dry run while testing. Live punch only when you uncheck dry run and Vinculum + UC are configured.

Reverse Delivery Challan

Select the warehouse, enter the Bulk Return ID. We download the credit note, read every line item from it, and build a Delivery Challan — works even when each CN layout differs.

Fallback: upload credit note PDF

Only if UC download fails. Same editor on the uploaded CN PDF.

Sheet Update

First fill: every Waypoint order — any status, whatever view the export came from — checked against Master, and only the new ones go to today's date tab. Second fill adds Unicommerce invoice data to those rows. Type SO numbers below and either fill will pull the order straight from Unicommerce, warehouse included — that is how orders Waypoint has not published yet still reach the sheet.

Master is now an IMPORTRANGE mirror of the B2B View source, so it refreshes itself — nothing here needs to sync it, and nothing may write to it (writing into the formula would replace it with #REF! and stop the refresh). To get date-tab rows into Master, paste them into the source sheet and the mirror brings them back. The Push and Sync buttons below are kept only for a Master that is not a mirror; against a mirror they refuse and explain why.

Master working-copy sheet ↗ Open in Google Sheets

One SO per line (commas work too). On the first fill these are added on top of the Waypoint sweep, resolved from Unicommerce — marketplace, PO, quantity, value, destination and the pickup warehouse. On the second fill each one is topped up with its invoice, invoice qty, tracking, e-way bill and status; an SO on no date tab is created from Unicommerce first. Leave empty for the unattended behaviour: Waypoint sweep, and enrich every row that still has no invoice.

Use Sync when you want Master to match the main B2B View sheet row-for-row.

Browser Extensions

Some automations use a small Chrome extension. Download, install once, and follow the steps below.

① Opptra Session Helper recommended

Captures your Unicommerce session after you log in, so the platform can keep it alive. You install it once; then whenever the session expires you just log into Unicommerce and click the helper.

⤓ Download Session Helper (.zip)
  1. Download the .zip above and unzip it to a folder you'll keep (e.g. ~/opptra-session-helper).
  2. Open Chrome → go to chrome://extensions.
  3. Turn on Developer mode (top-right toggle).
  4. Click Load unpacked → select the unzipped folder.
  5. Open the extension, paste your Ingest Token (get it from the Admin tab → “Session Helper token”) and the platform URL. Click Save.
  6. When the platform says “Re-login needed”, click Re-login to Unicommerce, log in (do the CAPTCHA), then click the helper’s Capture session. Done, session goes ALIVE.

② Bulk Invoice / E-way Bill Downloader

Select orders in Unicommerce and bulk-download invoice + e-way PDFs. Standalone, no token needed.

⤓ Download Bulk Downloader (.zip)
  1. Download and unzip the .zip above.
  2. Chrome → chrome://extensions → enable Developer mode.
  3. Load unpacked → pick the unzipped folder.
  4. Open Unicommerce, go to the orders list, click the extension, choose what to download.

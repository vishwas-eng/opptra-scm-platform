Browser Extensions

① Opptra Session Helper recommended

⤓ Download Session Helper (.zip)
  1. Download and unzip to a folder you’ll keep.
  2. Chrome → chrome://extensions → enable Developer mode.
  3. Load unpacked → select the unzipped folder.
  4. Paste your Ingest Token (Admin → Session Helper token) and platform URL → Save.
  5. When re-login is needed: log into Unicommerce, then helper → Capture session.

② Bulk Invoice / E-way Bill Downloader

⤓ Download Bulk Downloader (.zip)
  1. Download and unzip.
  2. Chrome → chrome://extensions → Developer mode → Load unpacked.
  3. In Unicommerce orders list, use the extension to download.
